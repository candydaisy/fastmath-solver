# FastMath
[![Live Demo](https://img.shields.io/badge/Live%20Demo-Calculator-blue?style=for-the-badge&logo=vercel)](https://fastmath-solver.vercel.app/)
A small web front end for the FastMath number solver.

## Run

```bash
pip install -r requirements.txt
python app.py
```

Then open **http://localhost:5000**.
